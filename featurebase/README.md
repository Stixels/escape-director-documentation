# Featurebase Messenger copies

These four Markdown files are curated copies for the Featurebase Messenger Help module. The canonical Product Guides remain in this repository's published GitBook tree.

When a canonical guide changes:

1. Review the matching Featurebase copy.
2. Keep only the operational steps useful inside the Messenger.
3. Preserve the canonical Product Guide link.
4. Paste the reviewed Markdown into Featurebase.
5. Confirm headings, lists, links, and images render correctly in the Messenger.

Do not add Featurebase-only operating instructions. Update the canonical Product Guide first.

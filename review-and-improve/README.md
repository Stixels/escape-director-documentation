# Review and Improve

Use the review tools after Room Sessions have been saved.

## Choose a view

| Goal | Open |
| --- | --- |
| Inspect individual runs, notes, or action history | [Room Statistics](view-room-statistics.md) |
| Understand patterns across completed Room Sessions | [Analytics](use-analytics.md) |

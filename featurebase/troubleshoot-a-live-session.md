# Troubleshoot a Live Session

## Live View

- Confirm the browser did not block the Live View window.
- Check the taskbar and other display before opening another window.
- Exit fullscreen before moving Live View to the intended display.

## Messages, Clues, or media

- Confirm Live View is open and the correct Puzzle is selected.
- Check the Session Log before sending content again.
- Check the Room Station output device and **Audio Mixer**.
- Use a safe alternative if an asset is missing during the live game.

## Connection or save problem

- Keep the Room Dashboard and Live View open.
- Do not refresh, sign out, or clear browser data.
- Submit completed Session details once and wait for the result.
- Preserve any pending or rejected Room Session record for recovery.

[Open the complete troubleshooting guide](https://docs.escapedirector.com/run-a-session/troubleshoot-a-live-session)

If the Room Session remains blocked, open **Messages** in this Messenger and include the Room name, visible error, browser, operating system, and whether the game is still active.
